# DESIGN

0. 넌 20년차 프론트엔드 최고참 시니어 엔지니어의 역할을 수행해야해.

1. 프롬프트 명령 잘 이행하도록.

2. 색상은 항상 색상 토큰(black100, 200)을 두고 그것으로 시멘틱 색상을 추가하여(PrimaryColor) 그것을 사용하도록 해주세요.

3. api키는 절대 그냥 코드에 하드코딩해선 안돼

4. CSS는 테일윈드를 사용해줘

5. 자주사용되는 숫자는 Const로 빼줘

6. 문자열은 반드시 별도의 Const로 빼고 하드코딩해선 안돼

7. 폴더 구조는 route-based로 해줘

8. react + vite 기반으로 만들어줘.

9. 새 화면/컴포넌트를 디자인할 땐 `design-new-page` 스킬을 참고해 (DESIGN.md 토큰, reference/ 폴더 구현 사례, 타임어택 톤, 와이어프레임 처리 방식을 다룸).
